# Module 1 — Quick Retro & Reframe: Chain vs. Spec-Led

**Opening session — AI-Assisted Development for Laravel Teams: Half-Day Follow-Up**

## Overview

The session opens by finding out what actually happened since the core day — not in a long discussion, but a quick, shared-doc capture that sets the agenda for the rest of the session. It then reframes one specific habit the retro is likely to surface: building features through a long, ad-hoc chain of prompts rather than a single reviewable spec. This sets up Module 2, where the team mob-writes a real spec end to end.

## Learning objectives

By the end of this session, participants will be able to:

- State what's actually been used since the core day, and where the friction has shown up in real work
- Distinguish a prompting chain from spec-led development, in terms of what's checkable before code exists, what's reusable, and where review effort moves
- Recognise a prompting chain in their own recent work and see the equivalent spec-led version
