# Module 4 — Trial-Commitment Tracker

**For the facilitator.** Fill this in live, in the shared doc, in the last 15 minutes of the session. This is the one artefact from today most likely to determine whether anything actually changes.

---

## Format

```markdown
# What we're trialling before the next check-in

## Trial 1: [name it specifically]
- What: [the concrete thing being trialled]
- Owner: [named person]
- First step: [what happens this week, not eventually]

## Trial 2: [name it specifically — should be the evals first step]
- What:
- Owner:
- First step:

## Standing ownership
- Spec template owner (drives it forward on the next real story): [name]
- Evals owner (turns today's worked example into a habit): [name]
- Sign-off watcher (notices if today's sign-off agreement quietly lapses): [name]

## Next check-in
- Date/timeframe: [agree roughly, even informally]
```

---

## Facilitation notes

- **Cap it at one or two trials.** More than that dilutes ownership and rarely all happen. If the room wants to trial several things, pick the top two and note the rest as "later, not now."
- **One trial must be a first step on evals** — per today's agenda. If it doesn't come up unprompted, ask for it directly rather than letting the close skip it.
- **Names, not roles.** "The team lead" is not an owner. Get an actual person's name against each line before the session ends.
- **Save this somewhere durable** — the team's actual working repo or shared team doc, not just today's session doc. It's only useful if someone can find it again at the next check-in.
